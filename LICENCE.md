## 🧩 About

**RimWorld Companion** is a curated list of RimWorld open-source tools:

- **Overlays** — on-screen helpers, layout notes, colonist tracker, resource viewer
- **Quality-of-Life Helpers** — inventory manager, work priority overlay, research notes
- **Research Notes** — base layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Colonist Tracker — monitor health and needs at a glance
- Resource Overlay — view stockpiles and item counts
- Work Priority Viewer — inspect job assignments
- Time Control Notes — adjust game speed for study (0.1x to 5x)

### Wallhack
- Raid Radar — incoming threat indicators
- Map Reveal — reveal unexplored areas for planning
- Loot Highlighter — highlight valuable items on the map

### Aimbot
- Build Planner — preview structures before placement
- Zone Manager — organize stockpiles and growing zones
- Pathing Notes — study colonist movement patterns
